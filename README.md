## Reflectie

1. **Lokale vs. remote repository:** Lokaal staat op mijn pc, remote staat op GitHub.

2. **`git push`:** Stuurt wijzigingen naar GitHub.

3. **`git pull`:** Haalt wijzigingen van GitHub naar mijn pc.

4. **`origin`:** De standaardnaam voor de remote repository.

5. **Waarom pullen:** Omdat de wijziging op GitHub stond en nog niet lokaal aanwezig was.
